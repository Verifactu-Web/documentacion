# ADR-0005: suscripción + volumen

**Estado:** aceptado · **Fecha:** 2026-10-01

El precio solo por ticket es imprevisible para retail y hostelería. Se adopta una cuota base con tickets incluidos, exceso por bloques, add-ons por sede/POS y Enterprise. El ledger interno conserva el metering y los derechos incluso si cambia el PSP.
