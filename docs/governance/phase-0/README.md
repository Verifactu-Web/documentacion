# Fase 0 — Gobierno, alcance y equipo

**Estado:** borrador operativo para aprobación del fundador y revisión legal/fiscal externa  
**Fecha de baseline:** 2026-10-01  
**Responsable de aprobación:** fundador/product owner  
**No es asesoramiento jurídico ni fiscal.** Las decisiones fiscales que condicionen el producto deben quedar aprobadas por la consultoría externa y trazadas en el registro de decisiones.

## Objetivo de la fase

Dejar preparado un marco ejecutable para construir un SIF SaaS comercial con un único fundador-operador, usando Codex de forma intensiva para especificación, generación de código, pruebas y automatización, y reservando a la consultoría legal/fiscal la validación de interpretación, evidencias y declaración responsable.

## Decisiones que requieren firma externa

1. Modalidad inicial VERI*FACTU y tratamiento de incidencias, anulaciones, rectificativas y devoluciones.
2. Aplicabilidad a cada tipo de factura, operación de hostelería, propinas, anticipos y pagos divididos.
3. Contenido y formato final de QR, hash, encadenamiento, remisión y conservación.
4. Evidencias exigibles para la declaración responsable del productor.
5. Calendario de entrada en vigor aplicable a cada perfil de cliente y release.

## Regla de salida de Fase 0

Fase 0 queda cerrada cuando el fundador aprueba charter, alcance, RACI, presupuesto y gate; la consultoría externa confirma por escrito el baseline fiscal y los supuestos críticos; y el Project contiene el backlog estimado con una tarea trazable por cada entregable de las fases posteriores.
